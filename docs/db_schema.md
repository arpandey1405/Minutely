# Database Schema Documentation

Minutely uses a **Postgres** database (configured via `DATABASE_URL`) managed via **Prisma ORM**. Below is the relational structure, constraints, and data definitions.

---

## Entity Relationship Summary

The schema consists of five models connected by cascading foreign keys:

```
  +--------------+
  |     User     |
  +-------+------+
          | (1)
          |
          | (N)
  +-------v------+        (1)       +------------------+
  |   Meeting    +------------------>    Transcript    |
  +---+-----+----+  1-to-1 Relation +------------------+
      |     |
      |     | (1) 1-to-1 Relation   +------------------+
      |     +----------------------->     Summary      |
      |                             +------------------+
      | (N)
      | 1-to-Many Relation
  +---v----------+
  |  ActionItem  |
  +--------------+
```

---

## Model Schemas

### 1. User Model
Stores authenticated accounts (supports local credential hashing and Google OAuth).

| Field Name | Type | Attribute / Modifier | Description |
| :--- | :--- | :--- | :--- |
| `id` | `String` | `@id`, `@default(uuid())` | Primary key UUID. |
| `email` | `String` | `@unique` | Login email address. |
| `name` | `String?` | Optional | User's full name. |
| `avatarUrl` | `String?` | Optional | Google profile photo URL. |
| `password` | `String?` | Optional | Hashed password (null for OAuth users). |
| `googleId` | `String?` | `@unique`, Optional | Google account identifier. |
| `createdAt` | `DateTime` | `@default(now())` | Account registration time. |
| `updatedAt` | `DateTime` | `@updatedAt` | Last modification time. |

---

### 2. Meeting Model
Stores uploaded meetings, audio references, and processing pipeline state.

| Field Name | Type | Attribute / Modifier | Description |
| :--- | :--- | :--- | :--- |
| `id` | `String` | `@id`, `@default(uuid())` | Primary key UUID. |
| `userId` | `String` | Foreign Key | References `User.id` (Author). |
| `title` | `String` | | Title of the meeting. |
| `audioUrl` | `String?` | Optional | Cloudinary media link or local storage path. |
| `status` | `String` | | Status (`uploaded`, `transcribing`, `summarizing`, `done`, `failed`). |
| `createdAt` | `DateTime` | `@default(now())` | File ingestion time. |
| `updatedAt` | `DateTime` | `@updatedAt` | Last state transition time. |

* **Relational Rules**:
  * `user`: Connects to `User` table. onDelete behavior: `Cascade` (deleting a user deletes all their meetings).

---

### 3. Transcript Model
Stores raw Speech-To-Text transcripts generated by Whisper ASR.

| Field Name | Type | Attribute / Modifier | Description |
| :--- | :--- | :--- | :--- |
| `id` | `String` | `@id`, `@default(uuid())` | Primary key UUID. |
| `meetingId` | `String` | `@unique`, Foreign Key | References `Meeting.id`. |
| `text` | `String` | | Complete voice transcription text. |
| `createdAt` | `DateTime` | `@default(now())` | Text creation time. |

* **Relational Rules**:
  * `meeting`: Connects to `Meeting` table. onDelete behavior: `Cascade`.

---

### 4. Summary Model
Stores meeting abstracts and key decisions distilled by LLaMA.

| Field Name | Type | Attribute / Modifier | Description |
| :--- | :--- | :--- | :--- |
| `id` | `String` | `@id`, `@default(uuid())` | Primary key UUID. |
| `meetingId` | `String` | `@unique`, Foreign Key | References `Meeting.id`. |
| `summaryText` | `String` | | Paragraph summary highlights. |
| `decisions` | `String` | | Key decisions array serialized as a JSON string. |
| `createdAt` | `DateTime` | `@default(now())` | Summary generation time. |

* **Relational Rules**:
  * `meeting`: Connects to `Meeting` table. onDelete behavior: `Cascade`.

---

### 5. ActionItem Model
Stores checklist action items with assignees and due dates.

| Field Name | Type | Attribute / Modifier | Description |
| :--- | :--- | :--- | :--- |
| `id` | `String` | `@id`, `@default(uuid())` | Primary key UUID. |
| `meetingId` | `String` | Foreign Key | References `Meeting.id`. |
| `task` | `String` | | Description of the action item task. |
| `owner` | `String?` | Optional | Named assignee responsible for task. |
| `dueDate` | `String?` | Optional | Target completion date. |
| `isCompleted` | `Boolean` | `@default(false)` | Checkbox completion status. |
| `createdAt` | `DateTime` | `@default(now())` | Task generation time. |

* **Relational Rules**:
  * `meeting`: Connects to `Meeting` table. onDelete behavior: `Cascade`.
